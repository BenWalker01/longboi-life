static void com.spacecomplexity.longboilife.game.utils.GameUtils.updateSatisfactionScore ( World  world)
static

Update satisfaction score.

Satisfaction score is calculated using Constants#satisfactoryDistance. For each accommodation building a modifier is created which is updated based on the positioning of other buildings with on Constants#satisfactoryDistance. After all modifiers are calculated the worst one is chosen to act as the satisfaction modifier, this then updates the satisfaction velocity.

Parameters
worldthe world reference for buildings.
